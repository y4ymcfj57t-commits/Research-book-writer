# Quality Gates: Pass/Fail Criteria

This document defines explicit pass/fail criteria for each production stage. A project cannot advance to the next stage without passing the relevant quality gate.

---

## Gate 1: Research Complete → Ready to Draft

**Must pass ALL criteria to proceed to drafting.**

### Source Coverage

| Criterion | Pass | Fail |
|-----------|------|------|
| Primary source identification | 80%+ of known primary sources identified | Significant known sources not yet identified |
| Archive access | All critical archives visited or access confirmed | Critical archives unvisited without access plan |
| Source intake | All gathered sources processed through intake | Backlog of unprocessed sources |
| Source map | Initial source map created | No systematic tracking of what supports what |

```
GATE 1 CHECKLIST: SOURCE COVERAGE

[ ] PASS: Primary sources for each life period identified
    Evidence: ________________________________________________

[ ] PASS: Source discovery checklist substantially complete
    Completion %: ___________
    Gaps explained: __________________________________________

[ ] PASS: All gathered sources have completed intake forms
    Total sources: ___________
    Processed: ___________

[ ] PASS: Initial source map exists
    Location: ________________________________________________

[ ] PASS: Critical gaps identified with mitigation plan
    Gaps: ___________________________________________________
    Plan: ___________________________________________________
```

### Question Framing

| Criterion | Pass | Fail |
|-----------|------|------|
| Thesis | Clear thesis articulated | Vague or missing thesis |
| Scope | Scope defined and justified | Scope undefined |
| Controversies | Known controversies identified | Controversies unresearched |
| Research questions | Questions articulated | No clear questions driving research |

```
GATE 1 CHECKLIST: QUESTION FRAMING

[ ] PASS: Thesis statement is specific and arguable
    Thesis: _________________________________________________

[ ] PASS: Scope boundaries explicitly defined
    Included: _______________________________________________
    Excluded: _______________________________________________

[ ] PASS: Key controversies identified with positions mapped
    Controversies: __________________________________________

[ ] PASS: Research questions documented
    Primary question: _______________________________________
```

### Interview Completion

| Criterion | Pass | Fail |
|-----------|------|------|
| Critical interviews | All essential living sources interviewed | Essential sources not yet approached |
| Interview documentation | All interviews recorded and processed | Interview backlog |

```
GATE 1 CHECKLIST: INTERVIEWS

[ ] PASS: Essential interview subjects identified and contacted
    Completed: ______________________________________________
    Outstanding (with timeline): ____________________________

[ ] PASS: Completed interviews transcribed/processed
    Total interviews: ___________
    Processed: ___________
```

### Research Memo

| Criterion | Pass | Fail |
|-----------|------|------|
| Synthesis | Research memo synthesizes findings | No synthesis document |
| Structure | Preliminary chapter structure proposed | No structural thinking |

```
GATE 1 CHECKLIST: SYNTHESIS

[ ] PASS: Research memo completed
    Key findings: ___________________________________________
    Surprises: ______________________________________________
    Remaining questions: ____________________________________

[ ] PASS: Preliminary chapter structure drafted
    Number of chapters: ___________
    Structure type: _________________________________________
```

## Gate 2: Draft Complete → Ready for Verification

|-----------|------|------|
| Coverage | All planned chapters drafted | Missing chapters |
| Narrative | Coherent narrative from start to finish | Fragments or gaps |
| Front/back matter | Introduction and conclusion drafted | Missing framing |

```
GATE 2 CHECKLIST: COMPLETENESS

[ ] PASS: All chapters drafted
    Total chapters: ___________
    Complete: ___________

[ ] PASS: Manuscript reads as continuous narrative
    Known gaps: _____________________________________________

[ ] PASS: Introduction establishes thesis and approach
    Thesis clearly stated: [ ] Yes [ ] No

[ ] PASS: Conclusion resolves narrative and argument
    Argument completed: [ ] Yes [ ] No
```

### Claim Ledger

| Criterion | Pass | Fail |
|-----------|------|------|
| Population | Claim ledger entries for all significant claims | Claims untracked |
| Linking | Claims linked to sources | Unlinked claims |

```
GATE 2 CHECKLIST: CLAIM LEDGER

[ ] PASS: Claim ledger populated
    Total claims: ___________
    With source links: ___________

[ ] PASS: High-severity claims fully documented
    Critical claims: ___________
    Fully documented: ___________
```

| Motifs | Motif tracking established | No motif awareness |

```

    Worksheets done: ___________

## Gate 3: Verification Complete → Ready for Revision

**Must pass ALL criteria to proceed to revision.**

### Verification Coverage

| Criterion | Pass | Fail |
|-----------|------|------|
| Dates | All dates verified | Unverified dates without flags |
| Names | All names verified | Unverified names |
| Locations | All locations verified | Unverified locations |
| Quotations | All quotations verified | Unverified quotations |

```
GATE 3 CHECKLIST: VERIFICATION COVERAGE

[ ] PASS: Date verification complete
    Dates verified: ___________
    Flagged uncertain: ___________
    Unverified without handling: ___________

[ ] PASS: Name verification complete
    Names verified: ___________
    Corrections made: ___________

[ ] PASS: Location verification complete
    Locations verified: ___________
    Period corrections: ___________

[ ] PASS: Quotation verification complete
    Quotes verified to original: ___________
    Quotes verified to secondary: ___________
    Issues found and resolved: ___________
```

### Triangulation

| Criterion | Pass | Fail |
|-----------|------|------|
| Source thresholds | All claims meet minimum source requirements | Claims below threshold without justification |
| Contradictions | All contradictions resolved or acknowledged | Unaddressed contradictions |

```
GATE 3 CHECKLIST: TRIANGULATION

[ ] PASS: Source thresholds met
    Claims below threshold: ___________
    Justified exceptions: ___________
    Unjustified (must address): ___________

[ ] PASS: Contradictions addressed
    Contradictions found: ___________
    Resolved: ___________
    Acknowledged in text: ___________
```

### Red Team

| Criterion | Pass | Fail |
|-----------|------|------|
| Completion | Red team review conducted | No adversarial review |
| Action | Red team issues addressed | Outstanding red team issues |

```
GATE 3 CHECKLIST: RED TEAM

[ ] PASS: Red team review completed
    Key claims tested: ___________
    Survived: ___________
    Required hedging: ___________
    Cut: ___________

[ ] PASS: All red team issues addressed
    Issues raised: ___________
    Issues resolved: ___________
    Outstanding: ___________

## Gate 5: Copyedit Complete → Ready for Final

**Must pass ALL criteria for manuscript delivery.**

### Text Quality

| Criterion | Pass | Fail |
|-----------|------|------|
| Copyedit | Professional copyedit completed | Uncopyedited text |
| Author review | Author reviewed copyedits | Copyedits not reviewed |

```
GATE 5 CHECKLIST: TEXT QUALITY

[ ] PASS: Professional copyedit completed
    Copyeditor: ____________________________________________
    Date completed: ________________________________________

[ ] PASS: Author reviewed and approved copyedits
    Disputed edits resolved: [ ] Yes [ ] No
```

### Citation Accuracy

| Criterion | Pass | Fail |
|-----------|------|------|
| Format | All citations in correct format | Format errors |
| Completeness | All citations complete | Incomplete citations |
| Accuracy | Citation accuracy spot-checked | Unchecked citations |

```
GATE 5 CHECKLIST: CITATIONS

[ ] PASS: Citation format consistent and correct
    Style used: ____________________________________________
    Spot-check results: ____________________________________

[ ] PASS: All citations complete
    Incomplete citations found: ___________
    All resolved: [ ] Yes [ ] No

[ ] PASS: Citation accuracy verified
    Sample checked: ___________
    Errors found and corrected: ___________
```

| Criterion | Pass | Fail |
|-----------|------|------|
| Style sheet | Style sheet complete | No style sheet |
| Names | Name spellings consistent | Inconsistent spellings |
| Dates | Date formats consistent | Format inconsistency |

GATE 5 CHECKLIST: CONSISTENCY

[ ] PASS: Name spellings consistent throughout
